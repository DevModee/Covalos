
### Downloads

| System | File |
| --- | --- |
| Windows 10/11 x64 | `Covalos-Windows-x64-Setup.exe` |
| macOS, Apple silicon | `Covalos-macOS-arm64.dmg` |
| macOS, Intel | `Covalos-macOS-x64.dmg` |
| Linux x86_64 | `Covalos-Linux-x86_64.AppImage` or `Covalos-Linux-amd64.deb` |

Each file has a `.sha256` next to it. Windows is the primary platform; the macOS and Linux
builds are new and less tested (see the platform table in `docs/RELEASE.md`).

The Windows installer and the macOS app are not signed or notarized yet. Windows SmartScreen
and macOS Gatekeeper ask for confirmation on first launch; on macOS, right-click the app and
choose Open.
